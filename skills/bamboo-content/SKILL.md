# bamboo-content

Прочитайте docs/WORKFLOW.md, docs/BRAND.md, docs/DOMAIN.md и docs/COMMERCE.md по пути, заданному нативной точкой входа.
Рабочие данные — в content, команды из корня через python bamboo.py.

1. Прочитайте brief и выбранные паспорта. Определите цель, аудиторию и запрошенные форматы.
2. Проверьте совпадение намерения с существующими задачами. Для индексируемого материала заполните
   brief.seo: page_type, cluster, target_url/related_urls; для чистого соцформата используйте social.
   Спрос не известен — указать unknown.
3. Соберите разрешённую фактуру мастера. Неизвестные объём/глина/цена/наличие не придумывать.
4. Используйте bamboo-research для источников и культурной точности.
5. Напишите материал-ядро только нужного размера. Карточке не нужна искусственная статья-предшественник.
6. Подготовьте запрошенные форматы и реальные фото. Для короткого рекламного текста предложите
   три различающихся захода в variants.md, выберите сильнейший одним предложением. В pack.json
   только один выбранный вариант каждого формата. Несколько длинных статей без запроса не писать.
7. Запустите validate. Делегируйте факты, голос и SEO ролям bamboo-factcheck, bamboo-editor,
   bamboo-seo — максимум три одновременно, без рекурсии и параллельной записи одного файла.
8. Исправьте подтверждённые дефекты и снова проверьте. Максимум два цикла, затем нерешённые
   вопросы владельцу. Экспортируйте превью; подготовьте пустую человеческую рецензию.
9. Остановитесь перед человеческим утверждением. Не выставляйте за человека checks/reviewer.
   Публикация только через bamboo-publish по отдельному явному поручению.
10. После выхода материала используйте bamboo-analytics для предложений следующего шага,
    не переписывая правила и стратегию автоматически.

Если реальных субагентов нет, выполните те же роли последовательно и так это назовите.
Не придумывать ID запусков, результаты тестов, прочитанные источники или голос мастера.
Выход пользователю: путь превью, выбранные форматы, источники, конкретные нерешённые вопросы,
состояние validate и указание, что публичная отправка не происходила.
