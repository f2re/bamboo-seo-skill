# Примеры новой подачи

Это редакционные варианты, не новые факты о товарах и не автоматически опубликованные записи.

- vk-piala-question.txt — выбранная замена опубликованного поста: короткий вопрос, три опоры,
  один переход к статье. Статья уже существует; не обещаем в ней несуществующие реальные замеры.
- vk-piala-detail.txt — другой вход через кромку, а не сокращение того же списка.
- vk-piala-compare.txt — вход через сравнение геометрии без приписывания размера реальным товарам.
- article-piala.md — практический разбор с коротким ответом, смысловыми заголовками,
  акцентами и памяткой. Условные 100 мл отмечены как пример, не характеристика Bamboo.
- layout-piala.md — карта размещения настоящих фотографий для родного редактора.

Первый вариант выбран для текущего поста: он оставляет в ленте только критерии первичного
выбора, а край/основание переносит в связанную статью. Не публикуйте все три сразу.
Для нового контента чередуйте профили из docs/PUBLICATION_STYLE.md, а не повторяйте одну формулу.
Объем, размеры, масса, материал, покрытие, уход и состояние при конкретной редактуре сохраняются.
