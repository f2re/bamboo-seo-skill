# Карта оформления статьи о пиале

Это задание для родного редактора ВК/Ярмарки Мастеров, не свидетельство выполненной съёмки.
Тексты готовы отдельно. Фотографии здесь не приложены: использовать только реальные файлы
мастерской с подтверждёнными правами. Отсутствующее фото не заменять выдуманным товаром.

Обложка: одна пиала, простой фон, без мелких надписей. Заголовок оформляется полем редактора.
После вступления: предмет в руке. Подпись: «Объём и габариты описывают разные стороны выбора».
После раздела про объём: два подтвержденных уровня наполнения одного изделия, если сняты.
Числа на фото только после замера. Без съёмки оставить раздел текстовым, не обещать «наши замеры».
После раздела про край: реальный крупный план кромки. Подпись объясняет ракурс, не сочиняет свойства.
В разделе про пять кадров: реальные ракурсы одной пиалы; не пять случайных чаш из каталога.
Финальная вставка: выделенная цитатой короткая памятка-сообщение мастеру.

Параграфы статьи разделены пустой строкой. Заголовки в редакторе — настоящие подзаголовки,
не оставленные решётки Markdown. Выделить только краткие тезисы, не весь абзац.
Текст источников (если добавлены новые технические факты) — компактно в конце, не ссылки
на чужие магазины внутри каждой рекомендации.

Для HTML-экспорта after_block в photos определяет место конкретного снимка. Нельзя заполнять
его ссылкой на неснятое фото. На мобильном проверить первый экран, расстояния, подписи,
отсутствие горизонтальной прокрутки. Наличие HTML-превью не означает редактуру статьи в ВК.
