# Примеры, не данные магазина

product.template.json — незаполненный паспорт, намеренно confirmed=false.
Скопировать в content/products/ только для реально существующего изделия и проверить все поля.
backlog.json — гипотезы тем, спрос не измерен. Это не утверждённый контент-план.
metrics.synthetic.csv — искусственные значения исключительно для проверки импорта.
Не использовать их в отчёте о деятельности Bamboo Pottery.
