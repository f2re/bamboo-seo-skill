# Коммерческая SEO-модель Bamboo Pottery

Контент не должен существовать отдельно от реального ассортимента. Базовая модель:

```text
категория/коллекция
  ├─ конкретные изделия
  ├─ техника/термин
  └─ экспертные материалы
        └─ релевантный переход к категории, изделию или вопросу мастеру
```

## Типы страниц

- **product** — один подтверждённый экземпляр/товар; характеристики только из паспорта.
- **category** — группа реальных товаров: тяваны, пиалы, чайники, коллекция/техника.
- **article** — отвечает на информационный или исследовательский вопрос и ведёт к релевантной
  категории/изделию, если оно реально есть.
- **technique/term** — справочная сущность; не должна конкурировать с товарной страницей
  по чисто коммерческому намерению.
- **social** — ВК/сторис/карусель; не считается самостоятельной индексируемой SEO-страницей.

## Граф связей

Для каждой индексируемой страницы фиксировать:

- `page_type`;
- `cluster` — например `kurinuki`, `chawan`, `yixing-teapot`;
- главный пользовательский вопрос;
- связанный product/category;
- исходящие внутренние ссылки;
- CTA;
- измеряемое действие: product_click / lead / order.

Одинаковый ключ не означает одинаковое намерение. Одинаковое намерение у нескольких URL —
повод проверить объединение/перелинковку, а не автоматически удалять страницу.

## Карточка товара

Минимум: ID, название/тип, подтверждённые материал/техника/размеры/объём при наличии,
фото, авторство, цена/наличие если актуальны, ссылка на товар и источник характеристик.
Неизвестное остаётся `null`.

Расширенный шаблон: `examples/product.template.json`.
Шаблон категории: `examples/collection.template.json`.

## Внутренние ссылки

Статья не должна заканчиваться одинаковым рекламным абзацем. Ссылка выбирается по намерению:

- вопрос о выборе → категория или подходящие товары;
- техника → изделия, реально выполненные в этой технике;
- уход → только изделия, к которым рекомендации применимы;
- подарочный сценарий → актуальная подборка, а не несуществующий ассортимент.

`bamboo-seo` проверяет эту связь до публикации.
