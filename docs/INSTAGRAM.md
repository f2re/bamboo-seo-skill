# Instagram: стек и 15-дневный план

Instagram `@bamboopottery` — витрина процесса, продажи — во ВК. Контентный контур тот же, что для ВК:
фактура → проверка → человеческое утверждение. Новые части: навык `bamboo-reel` и внешний `ffmpeg-skill`.
Публикация — модулем `ig` по поручению владельца или вручную из приложения; автоматизация публикации охват не добавляет.

## Стек

| Что | Решение | Когда |
|---|---|---|
| Монтаж Reels | [kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill), локально, без ключей | сейчас |
| Ролики из фото, плашки | HyperFrames (HTML → MP4) | сейчас |
| Идеи, хуки, подписи | `bamboo-reel` (в этом репозитории) | сейчас |
| Публикация Reels | модуль `ig` (Instagram Login API + Yandex Object Storage) | после настройки |
| Статистика | `adelaidasofia/instagram-mcp` или Postiz | по желанию |
| Обложки и текстовые карточки | Remotion + remotion-dev/skills | позже |
| Не использовать | instagrapi, postzen (передача логина), auto-editor, PySceneDetect, MoviePy, mcp-video-editor | — |

Методику instagram-agent-skill берите как справочник; его скрипты рассчитаны на английский и
на русском тексте работают неверно.

| GSAP, Puppeteer | уже внутри HyperFrames | отдельно не ставить |
| claude-video (watch) | просмотр готового ролика агентом | не нужен: хватает контактного листа ffmpeg-skill |
| opus-sound-layer | CC0-звуки для роликов без живого звука | по желанию; свой звук приоритетнее |
| auto-editor, mlx-whisper, parakeet-mlx, mlx-audio, pyannote-audio, librosa | паузы, речь, спикеры, доли музыки | не нужны: в роликах мастерской нет речи и чужой музыки |
| ManimGX, Anatomy, three.js, OpenScreen | схемы, 3D, скринкасты | не нужны: бренд держится на живой съёмке |

Установка выполняется владельцем: проект не скачивает внешний код сам. Нужны Node.js 22+ и FFmpeg.
Для хук-карточек и субтитров в ffmpeg-skill FFmpeg должен содержать фильтры `drawtext` и `subtitles`
(`npx ffmpeg-skill doctor` покажет, чего не хватает).

```bash
ffmpeg -version && python3 --version && node --version
npx ffmpeg-skill --project                     # Claude Code
npx ffmpeg-skill --dir ./.agents/skills        # Codex и Antigravity
npx ffmpeg-skill doctor
npx skills add heygen-com/hyperframes          # скиллы HyperFrames для агента
npx hyperframes --help
python3 -m pip install --user yt-dlp
```

Внешние скиллы в git не коммитятся (`.gitignore`). Исходники — в `content/jobs/<slug>/raw/`,
результат — в `content/jobs/<slug>/out/`. Задание агенту для живой съёмки:

> Используй ffmpeg-skill: собери из raw/ ролик для Reels до 20 секунд по шаблону reels, хук-карточка
> на первые 2 секунды, проверь `check.py --platform reels` и покажи контактный лист.

Для ролика из фото: «Используй HyperFrames: 9:16, 30 кадров/с, фото из raw/ с медленным зумом,
плашки из reel.md, затем проверь через ffmpeg-skill».

## Подготовка

Профиль: имя «Bamboo · керамика для чая»; описание до 150 знаков только из подтверждённого;
ссылка — сообщество или магазин ВК; переключить в профессиональный аккаунт. 2–5 реальных текстов
мастера положите в `content/voice/`.

Съёмка: вертикаль 1080×1920 (карусель 1080×1350), 30–60 кадров/с, штатив, боковой свет из окна.
Каждое действие — тремя планами: общий, руки крупно, фактура. Пишите живой звук.

| Сцена | Что снять | Дни |
|---|---|---|
| Куринуки | блок → вырезание → форма, крупно нож и петля | 1, 9 |
| Глазурь до/после | один ракурс и свет | 3 |
| Пиала в деле | наливание чая, 10–15 с без склеек | 4, 13 |
| Ваза с фактурой | общий, фактура, дно, интерьер | 5 |
| Печь | загрузка и открытие | 6 |
| Неудача | трещина или скол как есть | 7 |
| Мастерская | рабочее место, инструменты, круг, полки | 11 |
| Путь изделия | одна вещь на каждом этапе | 12 |
| Фото каруселей | пиалы рядом, в руке, край, дно, наличие | 2, 8, 14 |

## План на 15 дней

10 Reels и 5 каруселей, одна публикация в день. `{{N}}` заполняет мастер.

| День | Формат | Тема и хук | Сигнал |
|---|---|---|---|
| 1 | Reels 12–20 с | Куринуки: «Эта чаша была цельным куском глины», закольцован | досмотры |
| 2 | Карусель | «Пиала по фото: 5 кадров, которые стоит попросить у мастера» | сохранения |
| 3 | Reels 8–12 с | Глазурь до и после | пересылки |
| 4 | Reels 10–15 с | Пиала в деле: «Так она звучит, когда наливаешь чай» | досмотры |
| 5 | Карусель | История одной вазы, подпись в жанре vk-detail | сохранения |
| 6 | Reels 15–25 с | «Открываю печь после {{N}} часов обжига» | досмотр до конца |
| 7 | Reels 10–20 с | «Эта чаша не пережила обжиг» | комментарии |
| 8 | Карусель | Тяван, пиала, чашка — по docs/DOMAIN.md | сохранения |
| 9 | Reels 20–30 с | От блока до чаши: «30 секунд вместо {{N}} часов» | досмотры |
| 10 | Reels 10–20 с | Ответ видео на комментарий | комментарии |
| 11 | Карусель | «Где делают эти чаши» | переходы в профиль |
| 12 | Reels 15–20 с | «{{N}} дней одной пиалы за 20 секунд» | досмотры |
| 13 | Reels 10–15 с | Заварка в чайнике Bamboo, закольцован | пересылки |
| 14 | Карусель | Изделия в наличии — размеры и объём из паспорта | сообщения |
| 15 | Reels | Лучший формат дней 1–13 с новым хуком | проверка формата |

Если публиковать ежедневно не получается, пропускайте карусели дней 8 и 11.

## Правила для каждого Reels

- Хук на экране в первые 2 секунды, до 7 слов; действие с первого кадра.
- 7–30 секунд; последний кадр перекликается с первым.
- Только свой звук и своя съёмка.
- Суть подписи — в первых 125 знаках; слова поиска обычным текстом.
- 3–5 точных хэштегов; один призыв на публикацию.
- Обложка с изделием в центре (сетка профиля обрезает до 3:4).
- Объём, размеры и техника — только из паспорта изделия.

## Метрики и решения

Для Reels смотрите время просмотра и пересылки на охват; оценка — не раньше 72 часов после публикации.
Фиксируйте по дням: просмотры, среднее время, пересылки, сохранения, подписки, вывод.

1. День 7: сравните Reels дней 1, 3, 4, 6, 7 по пересылкам на 1000 просмотров и среднему времени;
   лучший тип повторите на днях 9–13 вместо самого слабого.
2. День 15: лучший формат — основа около половины публикаций следующего цикла, худший уберите.
3. Слабые ролики не удаляйте и не перезаливайте: повтор считается неоригинальным.

Рутина: 60–90 минут в день; ответы на комментарии в первый час; 5–10 содержательных комментариев
у профильных аккаунтов — вручную.

## Публикация: модуль `ig`

Свой модуль на официальном Instagram API with Instagram Login (`graph.instagram.com`, без страницы
Facebook). Ролик загружается в закрытый бакет Yandex Object Storage, Instagram получает временную
подписанную ссылку на 2 часа, после публикации файл удаляется. Музыку из библиотеки Instagram через
API добавить нельзя: в ролике остаётся его собственный звук.

### Настройка (один раз)

1. **Профессиональный аккаунт**: Instagram → Настройки → Тип аккаунта и инструменты →
   Переключиться на профессиональный (тип «Автор» или «Бизнес»).
2. **Приложение Meta**: developers.facebook.com → My Apps → Create app → тип Business →
   добавить продукт **Instagram** → «API setup with Instagram login». Добавьте `@bamboopottery`
   в роли приложения (Instagram Tester) и примите приглашение в Instagram:
   Настройки → Приложения и сайты → Приглашения тестировщиков.
3. **Ключ Instagram**: на той же странице «Generate access tokens» → выберите аккаунт → скопируйте
   ключ (долгий, около 60 дней; нужны права `instagram_business_basic` и
   `instagram_business_content_publish`). Затем:
   ```bash
   python bamboo.py ig token-import
   ```
   Ключ продлевается автоматически при использовании, когда ему больше суток и до конца срока
   меньше 30 дней. Если не пользоваться модулем 60 дней — получите ключ заново.
4. **Yandex Object Storage**: console.yandex.cloud → Object Storage → создать закрытый бакет
   (имя без точек). Сервисный аккаунт с ролью `storage.editor` на бакет → создать статический
   ключ доступа. Затем:
   ```bash
   python bamboo.py ig init --bucket ИМЯ_БАКЕТА
   python bamboo.py ig storage-key-import
   python bamboo.py ig check
   ```
   `check` показывает аккаунт, лимит публикаций и доступ к бакету; ничего не публикует.

Ключи хранятся в `~/.config/bamboo/ig.json` (chmod 600, вне репозитория) либо в переменных
`BAMBOO_IG_ACCESS_TOKEN`, `BAMBOO_YC_KEY_ID`, `BAMBOO_YC_SECRET`.

### Публикация

В пакете: ролик в `pack.videos`, подпись — формат `instagram` (text + cta, до 2200 знаков,
не больше 5 хэштегов). После одобрения владельца (`approve SLUG --owner ИМЯ`):

```bash
python bamboo.py ig plan-post SLUG --request "Поручение владельца"
python bamboo.py ig apply PLAN_ID --confirm "ig:…" --execute
```

`plan-post` не обращается к сети. `apply` загружает ролик, создаёт контейнер REELS, ждёт
обработки до 5 минут, публикует и возвращает ссылку. Если Instagram ещё обрабатывает видео
или ответ на публикацию потерян, повторите ту же команду: используется тот же контейнер,
а он не публикуется дважды. Лимит Instagram — 100 публикаций через API за сутки.

## Риски

- **Реклама.** С 1 сентября 2025 в России запрещено размещать рекламу в Instagram. Перед публикацией
  дня 14 и ссылок на магазин уточните у юриста; это не юридическая консультация.
- **Автоматизация действий** (подписки, комментарии, лайки) нарушает условия Instagram; агент готовит
  тексты и монтирует, отвечаете и комментируете вы.
- **Аудитория**: часть зрителей заходит через VPN; ролики без речи понятны шире.
- **Пробные Reels** по данным сторонних сервисов — от 1000 подписчиков; проверьте в приложении.
- Метрики и ранжирование из сторонних источников — ориентир, а не гарантия.
