# Reels Bamboo Pottery

Редакционное решение от 13 октября 2026. Reels собирается только из собственной съёмки
мастера: руки, глина, инструмент, печь, готовая вещь в деле. Правила ниже — рабочий стиль
Bamboo и опубликованные ограничения Instagram, не «секрет алгоритма» и не прогноз охватов.

## Что делает ролик рабочим

- **Своё.** Собственная съёмка и живой звук мастерской. Чужие ролики, перезаливы и водяные
  знаки других платформ не используются: с мая 2026 Instagram не рекомендует аккаунты,
  которые в основном публикуют неоригинальный контент.
- **Действие в первом кадре.** Без приветствия, анонса и «досмотри до конца». Хук на экране —
  до 7 слов в первые 2–3 секунды.
- **Короткий план.** Для первых роликов 7–30 секунд; кадр без смены плана — до 6 секунд.
  Не растягивать ради нормы и не обрезать то, ради чего ролик снят.
- **Петля.** Последний кадр перекликается с первым: снова блок глины, снова закрытая печь.
- **Один призыв.** «Отправьте тому, кто…», «сохраните, чтобы…» или вопрос — что-то одно.
- **Подпись.** Суть — в первых ~125 знаках, столько видно до «ещё». Слова, по которым ищут,
  пишутся текстом: керамика, пиала, тяван, куринуки, чайная посуда. Хэштеги — отдельно,
  3–5 точных; общие вроде #reels не помогают. Instagram принимает не больше пяти.
- **Обложка.** Кадр с изделием в центре: сетка профиля показывает обложку в формате 3:4.
- **Факты.** Объём, размеры, техника, назначение и число часов работы — только из паспорта
  изделия и claims, как требует docs/BRAND.md. Текст на экране проверяется так же, как подпись.

## Формулы хуков

Это способы начать ролик, а не шаблоны для подстановки. Для каждого ролика — три хука из
разных формул в variants.md, в pack — один. `{{…}}` заполняет мастер; без значения формулу
с числом не использовать.

| Формула | Хук на экране | Когда подходит | Как испортить |
| --- | --- | --- | --- |
| Сжатие времени | «{{N}} часов резьбы за 20 секунд» | Долгий процесс, снятый целиком | Придумать N |
| До и после | «Так эта глазурь выглядела до печи» | Сырая и готовая вещь в одном ракурсе | Разный свет и ракурс «до» и «после» |
| Холодный старт | «Чаша из цельного блока» | Сильное первое действие: нож входит в глину | Начать с неподвижного стола |
| Раскрытие | «Открываю печь» | Открытие печи, снятие плёнки, первый взгляд | Показать результат в первом кадре |
| Неудача | «Эта чаша не пережила обжиг» | Трещина, скол, брак — как есть | Придумать причину, которую мастер не знает |
| Дословный вопрос | «„Небольшая пиала“ — это какая?» | Настоящий вопрос из комментариев или ВК | Сочинить вопрос и выдать за чужой |
| Лицом к лицу | «Две пиалы: тонкий край и толстый» | Сравнение двух реальных вещей в руке | Сравнивать с чужим товаром |
| Неправильно и правильно | «Так пиалу на фото не видно» | Практический совет по выбору или уходу | Стыдить зрителя |
| Возражение | «Почему ручная пиала дороже магазинной» | Есть честный ответ: время, брак, обжиги | Обещать рост стоимости или «лучший вкус» |
| С середины | «…и петля прошла насквозь» | Острый момент процесса, начало не нужно | Обрыв без продолжения в кадре |
| Звук | «Так звучит чай в этой пиале» | Наливание, скрип ножа, шорох глины | Наложить чужую музыку поверх звука |
| Угадайте | «Угадайте цвет после обжига» | Глазурь меняет цвет в печи | Не показать ответ в конце |
| Деталь крупно | «Посмотрите на край этой чаши» | Фактура, след инструмента, дно | Мыльный макро-кадр |
| Одна цифра | «{{объём}} мл — до какого уровня?» | Параметр из паспорта, который трудно понять по фото | Число без claim |

Не использовать: «никто не расскажет», «секрет», «вы не поверите», «стоп, листай»,
«успейте». validate отмечает кликбейт, приветствие и просьбу о внимании.

## Поле reel в pack.json

`python bamboo.py new SLUG --topic "…" --formats reel` создаёт пустое поле и папку
`content/jobs/SLUG/raw/` для исходников.

```json
{
  "text": "Пиалу вырезали из цельного блока глины. [[kurinuki-fact]]",
  "cta": "Отправьте тому, кто пьёт чай из кружки.",
  "claims": ["kurinuki-fact"],
  "hook": "Эта чаша была куском глины",
  "beats": [
    {"start": 0, "end": 2, "shot": "Нож входит в блок", "onscreen": "Эта чаша была куском глины",
     "clip": "content/jobs/SLUG/raw/carve.mp4", "source_in": 12},
    {"start": 2, "end": 7, "shot": "Петля выбирает объём", "onscreen": "Внутри — слой за слоем",
     "clip": "content/jobs/SLUG/raw/carve.mp4", "source_in": 140},
    {"start": 7, "end": 11, "shot": "Готовая пиала в руке, рядом снова блок",
     "clip": "content/jobs/SLUG/raw/bowl.mp4"}
  ],
  "footage": [
    {"path": "content/jobs/SLUG/raw/carve.mp4", "origin": "camera", "rights_confirmed": true},
    {"path": "content/jobs/SLUG/raw/bowl.mp4", "origin": "camera", "rights_confirmed": true}
  ],
  "hashtags": ["#керамика", "#пиала", "#куринуки"],
  "cover_at": 9
}
```

- `text` — подпись, `cta` — один призыв, `hashtags` — до пяти, без пробелов.
- `beats` — время в итоговом ролике, по порядку и без наложений. `shot` описывает реальный
  кадр из исходника, `onscreen` — текст поверх (перенос строки — `|`).
- `clip` и `source_in` — какой файл и с какой секунды взять кусок длиной `end − start`.
  Без `source_in` берётся весь файл: обрежьте его заранее или укажите отметку.
- `footage` — только собственная съёмка в `content/jobs/SLUG/raw/` или `content/media/video/`,
  mp4/mov/m4v, с подтверждёнными правами. Исходники не изменяются.
- `cover_at` — секунда для кадра обложки, необязательно.

## Монтаж через ffmpeg-skill

Установка в проект: `npx ffmpeg-skill --project` для Claude Code,
`npx ffmpeg-skill --dir ./.agents/skills` для Codex и Antigravity. Нужны `ffmpeg` и `python3`.

`python bamboo.py export SLUG` кладёт в `exports/SLUG/`:

| Файл | Что внутри |
| --- | --- |
| `reel.txt` | Подпись с призывом и хэштегами — для вставки в Instagram |
| `reel-cues.txt` | Текст на экране по кадрам в формате `caption.py --text` |
| `reel-project.json` | Проект `render.py`: куски исходников, 9:16, хук-карточка, титры, −14 LUFS, проверка под Reels |
| `reel.json` | Сводка: хук, длительность, кадры, исходники, команды монтажа |

Затем, из корня проекта:

```sh
python3 <ffmpeg-skill>/scripts/render.py exports/SLUG/reel-project.json --dry-run --json
python3 <ffmpeg-skill>/scripts/render.py exports/SLUG/reel-project.json
python3 <ffmpeg-skill>/scripts/check.py exports/SLUG/reel.mp4 --platform reels
python3 <ffmpeg-skill>/scripts/look.py exports/SLUG/reel.mp4 --tiles 3x2
```

Проект склеивает куски в размере первого клипа и обрезает до 9:16 по центру. Снимайте
вертикально: горизонтальный кадр потеряет края, а изделие не по центру — уйдёт из кадра.
Перед планом — `probe.py` каждого исходника: длительность, частота кадров, ориентация.
Отметки `source_in` берутся из просмотренного контактного листа, а не угадываются.
После монтажа посмотреть лист `look.py`: не закрывают ли титры изделие и руки.
Экспорт сам видео не монтирует и в Instagram не отправляет.

## Публикация

Этот инструментарий не публикует в Instagram. По умолчанию владелец выкладывает
`reel.mp4` с подписью из `reel.txt` из приложения. Если подключён instagram-mcp и есть
прямое поручение на конкретный ролик, координатор публикует его инструментом `publish_reel`
по публичной https-ссылке на файл и сверяет результат через `get_media`. Неопределённый
ответ не повторять вслепую: сначала проверить ленту.

Продажу — цены, наличие, «как купить» — держите во ВКонтакте: с 1 сентября 2025 в России
запрещена реклама в Instagram. Как это касается продвижения своих изделий, уточняет юрист.

## Оценка

Ролик оценивается не раньше чем через 72 часа: просмотры, среднее время просмотра,
пересылки, сохранения, подписки. Цифры берутся из статистики Instagram, не оцениваются
на глаз. Решение — какой формат повторить, какой убрать — записывается в content/strategy.md.
