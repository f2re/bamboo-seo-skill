# Проверки поведения skills

Unit-тесты Python проверяют код, но не доказывают корректное поведение ИИ. Наборы в `evals/`
проверяют маршрутизацию и редакционные ограничения в Codex, Claude Code и Antigravity.

`routing.jsonl` — какой skill должен быть выбран.
`content.jsonl` — какие ограничения обязаны соблюдаться при выполнении задачи.

Локальная структурная проверка:

```bash
python tools/check_evals.py
```

Это не запуск модели. Для приёмки среды прогоните prompts в новой сессии каждой системы и
зафиксируйте фактический выбранный skill, вызванные роли и нарушение/соблюдение expectations.
Регрессионный релиз не должен уменьшать долю правильной маршрутизации или пропускать blocker-кейсы.
